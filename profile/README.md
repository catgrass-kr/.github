# 유온 · 고양이풀

### 사랑은 감으로 해도, 기록은 정확하게.

**소중한 일상 관찰을, 다시 찾을 수 있는 돌봄 기록으로.**

고양이풀은 반려묘 보호자를 위한 로컬 돌봄 기록 프로토타입입니다. 건강을 단정하는 대신, 보호자가 관찰한 사실과 변화에 집중합니다.

## 더 차분하게 돌보기 위한 기록

- **관찰과 해석 구분하기** · 무엇을 보았는지, 언제 달라졌는지 남길 수 있는 기록의 관점을 제안합니다. 진단은 기록과 다릅니다.
- **개인적인 일상 존중하기** · 개인정보 지원 시스템 개발 경험을 바탕으로, 민감한 돌봄 정보를 신중하게 다루는 로컬 중심 설계를 지향합니다.
- **사람이 쓰기 쉬운 흐름** · 웹 개발 경험과 사회복지에 대한 관심을 바탕으로, 바쁜 보호자도 이해하기 쉬운 작은 도구를 탐색합니다.

## 기록할 때 기억할 것

1. 날짜와 관찰한 사실을 함께 남기기.
2. 추측은 사실과 구분하기.
3. 걱정되는 변화가 있다면 기록을 참고해 수의사와 상담하기.

## 프로젝트 안내

**로컬 돌봄 기록 프로토타입**입니다. 의료 서비스가 아니며, 질병 진단·처방·치료 권고를 제공하지 않습니다. 응급 상황이나 건강 문제는 수의사의 도움을 받아 주세요. 현재 제공 범위와 데이터 보관 안내는 웹사이트에서 확인할 수 있습니다.
